# AGENT.md

This repository is a custom QMK keyboard firmware, maintained by the user (sitaktif).

The main custom firmware for this setup is:

`keyboards/keychron/q0/plus/keymaps/sitaktif/keymap.c`

Work on this keymap is the priority when making changes for the user's keyboard.

## Commit messages

- Do not add a `Co-Authored-By` trailer to commit messages.
- A `Claude-Session` trailer is fine to include.
